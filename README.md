## Mẹo làm bài

Câu hỏi dạng tình huống: đáp án đúng thường là đáp án **an toàn, có kiểm chứng, có human review, phù hợp mục tiêu kinh doanh** — không phải đáp án "mạnh nhất" hay "tự động nhất".
